# 消息系统
- 支持好友私聊。
- 消息长度限制为 500 字以内。
- 消息窗口尺寸更小，适合悬浮在播放界面上。
- 可拖拽窗口顶部移动位置。
- 可拖拽窗口底部旋转，形成 3D 悬浮效果。
- 收到新消息时，左侧空白处会出现消息气泡。
- 消息气泡可关闭，也可直接回复。
- 社区页提供消息免打扰按钮，开启后不再弹出新消息气泡。
 ###  点赞、听歌时长与认证

- 好友之间可以点赞。
- 客户端会上报听歌时长和当前播放歌曲。
- 服务器根据听歌时长和点赞数自动生成认证：
  - 活跃乐友。
  - 认证乐友。
  - 深度乐友。
- 服务端手动徽章优先级高于自动认证。
- 手动徽章可在服务器后台下发或清除。
### 一起听歌

一起听歌用于让好友在同一首歌上保持播放同步。

### 支持流程：

- 向在线好友发起一起听邀请。
- 对方可同意或拒绝。
- 同意后创建一起听会话。
- 任一成员切换歌曲、播放/暂停或进度变化时，服务器会发布同步事件。
- 其他成员收到同步事件后尝试选中同一首歌并播放。
- 任一成员可退出一起听，服务器会通知会话成员。
- 连麦信令可通过社区服务器中转，为语音或 WebRTC 能力预留通道。

### 本地桌宠加密记忆

- 桌宠聊天、歌曲/歌单、播放动作、命令执行和场景预设会写入本机的加密记忆库；聊天记录与操作记录分开保存，并同时保留事件发生时间和记忆库接收时间，方便追溯。
- 记忆库位于客户端数据目录的 `local-ai-memory` 下。主密钥只以 Windows 当前用户 DPAPI 密文保存，记录本身使用认证加密；加密能力不可用时会停止持久化，不会降级写入明文。
- 已登录账号优先按服务器不可变账号主体隔离；服务器主体尚未下发或暂时离线时，会为该音乐平台账号生成并持久化一个随机、不透明的本机主体，不会退回共享匿名库。服务器绑定以后到达也不会移动原本地库。未登录时使用本设备匿名空间；可修改的 FE ID 仅作为显示或后续备份索引，不参与本地加密身份和密钥派生。
- 临时对话只保留在当前页面内存，不进入桌宠历史 localStorage、本地加密库、备份或后续同步队列；结束临时对话后会丢弃本轮消息。普通对话默认写入当前账号分区的长期加密记忆。
- 本机回环地址上的自备模型会在每轮推理前读取有界的最近聊天、操作和知识记录；召回内容经过字段白名单、敏感信息过滤和非可信上下文隔离。询问桌宠是否具备记忆时，客户端直接检查记忆库状态，不再让模型猜测。
- 支持按聊天、操作或知识记录显式删除，也支持创建和恢复 `.fememory` 加密备份。备份绑定现有记忆库及 Windows 用户密钥环境，不应当作跨电脑明文导出文件使用。
- 当前批次以本地加密库为权威来源，不会把本机解密后的召回内容静默发送给服务器模型。按 FE ID 的服务器备份补齐和跨设备恢复仍属于后续批次；服务器模型继续使用服务器端 FE ID 记忆，本地自备模型使用本机加密记忆。
