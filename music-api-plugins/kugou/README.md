# FE Monster 酷狗音乐 API 插件

版本：1.5.1  
上游源码：MakcRe/KuGouMusicApi `283f1e97b110726b208a64b486a657c0fc0a6126`

在 FE Monster 登录窗口中点击“导入 API 插件”并选择本 ZIP。导入后，
登录窗口会自动识别酷狗音乐并添加平台切换按钮。插件会由 FE Monster 使用其
内置 Node.js 在本机 `127.0.0.1:3012` 启动，不会监听局域网地址。

支持：

- 酷狗 App 扫码登录（key / create / check）
- 歌曲搜索与标准音质播放地址
- 登录状态、账户信息、用户歌单与歌单详情

插件仅供互操作、学习与个人使用。接口可能随酷狗上游变更而失效；VIP 或
受版权限制的歌曲仍受账号权限与地区限制。
