# FE Monster 汽水音乐 API 插件

此插件把 `SolitudeKing/music-lib` 的汽水音乐能力适配为 FE Monster 本地 API：歌曲与歌单搜索、歌单歌曲、歌词、个人歌单、应用内扫码登录，以及带解密和 Range 支持的本地音频代理。

## 登录

- 应用内二维码会调用汽水官方二维码会话。汽水的风控签名可能使部分会话进入限流或二次验证，此时请使用 FE Monster 登录页中的“官方浏览器登录”。
- 官方浏览器登录使用独立的 Edge/Chrome 资料目录；登录凭据只保存在本机，不会出现在网页响应或日志中。
- 插件也可读取数据目录中的 `cookie.txt`，或启动时的 `QISHUI_COOKIE` 环境变量。

## 播放

汽水返回的部分音频经过加密，不能直接交给 HTML 音频元素。插件会在 `127.0.0.1` 上下载并解密到有界缓存，再以支持 HTTP Range 的本地地址播放。VIP 或无音源歌曲仍受账号权限与平台可用性限制。
